# INFERNUM

3D-шутер от первого лица в стиле классического **Doom** (1993). Работает прямо в браузере:
движок — [Three.js](https://threejs.org/) (WebGL), сборка — [Vite](https://vite.dev/).

Вся графика, звуки и музыка **генерируются кодом** при запуске — в репозитории нет ни одной
картинки или аудиофайла.

## Что есть в игре

- 2 уровня: **E1M1 «Ангар»** (марсианская база) и **E1M2 «Адские врата»** (лава, храм и арена с боссом).
- Уровни «в духе Doom»: разная высота пола и потолка, лестницы, открытое небо, секторное освещение,
  двери (в том числе запертые на цветные ключи), кислота и лава, наносящие урон.
- 5 видов оружия: кулак, пистолет, дробовик, пулемёт, ракетница.
- 5 видов монстров: зомби, сержант, имп, демон и босс — Барон ада. Монстры слышат выстрелы,
  ищут путь к игроку и умеют открывать двери.
- Взрывающиеся бочки, аптечки, броня, патроны, ключи.
- Статус-бар с лицом героя, автокарта, статистика уровня, 3 уровня сложности.
- Спрайтовые враги-«билборды» и пиксельные текстуры 64×64, режим «ретро-пиксели» (низкое разрешение).
- Синтезированные звуки и музыка (WebAudio).

## Управление

| Клавиши | Действие |
| --- | --- |
| `W` `A` `S` `D` / стрелки | движение (`←` `→` — поворот) |
| Мышь | обзор |
| ЛКМ / `Пробел` | огонь |
| `E` | открыть дверь |
| `Shift` | бег |
| `1`–`5`, колесо мыши, `Q` | смена оружия |
| `Tab` | автокарта |
| `M` | музыка вкл/выкл |
| `Esc` / `P` | пауза |

Цель каждого уровня — найти ключи и дойти до выхода: это площадка под зелёной табличкой «ВЫХОД»,
уровень завершается, как только вы на неё встанете.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 20.19+ или 22.12+.

```bash
npm install
npm run dev       # сервер разработки: http://localhost:5173
```

Сборка статической версии (результат — в папке `dist/`, её можно выложить на любой хостинг):

```bash
npm run build
npm run preview   # проверить сборку: http://localhost:4173
```

Тесты уровней (проходимость, достижимость ключей и выхода, столкновения):

```bash
npm test
```

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `index.html`, `src/style.css` | страница, меню и экраны |
| `src/main.js` | точка входа: состояния игры, настройки, главный цикл |

| `src/map.js` | карта-сетка: высоты, двери, столкновения, трассировка лучей, поиск пути |
| `src/levels.js` | описание уровней |
| `src/world.js` | построение 3D-геометрии уровня и неба (Three.js) |
| `src/player.js` | игрок и оружие |
| `src/entities.js` | монстры, снаряды, бочки, предметы, эффекты |
| `src/textures.js`, `src/sprites.js` | процедурные текстуры и пиксель-арт спрайты |

| `tests/levels.test.js` | автотесты уровней |

## Как добавить свой уровень

Уровни описаны в `src/levels.js`: это сетка клеток 1×1, в которой «вырезаются» зоны с заданной
высотой пола и потолка, освещением и текстурами (`m.carve`), ставятся двери (`m.door`) и
расставляются предметы и монстры (`m.thing`). После правок запустите `npm test` — тесты проверят,
что уровень проходим, а `DUMP=1 npm test` напечатает его ASCII-карту.
